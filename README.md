# personal-website

Личный сайт-визитка на Next.js + страница про Telegram-канал ([@pomazkovjs](https://t.me/pomazkovjs)) с семантическим поиском по постам и картой тем.

## Структура

- `/` — визитка (без ссылок на страницу канала).
- `/channel` — поиск по постам канала + карта тем (доступна только по прямому адресу).
- `app/api/search` — serverless-поиск: векторный (если сгенерированы эмбеддинги и задан `OPENAI_API_KEY`), иначе — по ключевым словам.
- `data/` — сгенерированные данные: `posts.json` (посты), `map.json` (2D-карта тем), `vectors.json` (эмбеддинги, base64).
- `scripts/prepare-data.mjs` — пайплайн генерации данных из экспорта Telegram.

## Локальный запуск

```bash
npm install
npm run dev
```

## Обновление данных канала

1. В **Telegram Desktop**: канал → «⋮» → Export chat history → без медиа → формат JSON (`result.json`) или HTML (`messages.html`). Положи экспорт в `data/raw/` (папка в .gitignore).
2. Ключ OpenAI: `export OPENAI_API_KEY=sk-...` (или добавь в `.env.local` и подгрузи в шелл).
3. Запусти пайплайн:

```bash
npm run prepare-data -- --export data/raw/messages.html --channel pomazkovjs
```

Скрипт: парсит экспорт → эмбеддинги `text-embedding-3-small` (512d, стоит копейки) → `gpt-4.1` читает все посты и строит таксономию тем (кластеризация k-means — только фолбэк при ошибке LLM) → supervised UMAP-проекция в 2D. Результат пишется в `data/`.

Без `OPENAI_API_KEY` скрипт запишет только посты (поиск будет работать по ключевым словам, карта тем скроется).

4. Выполни проверку и тюнинг тем по инструкции ниже. Только после этого коммить данные и публикуй сайт.

### После автоматического обновления: обязательно проверить темы

Автоматическая кластеризация — черновик. Она может придумать новые категории и потерять
прежнюю ручную разметку. Для обычного обновления архива сохраняем восемь тем, их ID и порядок
из `data/reviewed-topics.json`: от них зависят цвета на всей странице.

- Сохраняй проверенные назначения старых постов. Прочитай полностью новые и изменённые
  посты, затем добавь или поправь их ID в `assignments` файла `reviewed-topics.json`.
- Выбирай тему по главному содержанию: Стамбул — «Релокация и путешествия», бытовые
  истории — «Личное и мотивация», практический совет для macOS — «Будни разработчика».
  Разбор использования ИИ в Wise относится к «ИИ-инструментам», несмотря на название компании.
  Анонсы видео и новости собственного канала — «Жизнь канала».
- После правки запусти `npm run prepare-data -- --reviewed`. Этот режим использует уже
  созданные посты и эмбеддинги, применяет проверенную разметку и заново строит supervised UMAP.
  Ключ и обращения к API не нужны. Одних замен названий или цветов недостаточно:
  `posts.cluster`, `map.points.c` и координаты карты должны соответствовать одной разметке.
- Не меняй тексты постов между созданием эмбеддингов и этим шагом: индекс должен соответствовать
  текстам. При изменении текста сначала заново обработай экспорт.
- Проверь совпадение ID постов, точек и векторов, ссылки в `curated.json`, типы и сборку
  (`npx tsc --noEmit`, `npm run build`). Открой `/channel` на широкой и мобильной ширине:
  подписи карты, фильтры тем/лет, таймлайн, графики и поиск должны соответствовать данным.
- `curated.json` обновляется отдельно: проверь, появились ли новые серии или важные вехи.
  Не добавляй их автоматически ради заполнения блока.

Текущая проверенная разметка восстановлена 15 сентября 2026: прежние назначения сохранены,
17 новых постов распределены после чтения полного текста; отредактированный пост 295
остаётся в «Жизни канала». Новые категории вводим только при отдельном пересмотре структуры,
а не при каждом импорте. Успешный запуск скрипта сам по себе не означает, что редакционная
и визуальная проверка завершены.

## Деплой (Vercel)

1. Импортируй репозиторий в Vercel — фреймворк определится автоматически.
2. В настройках проекта добавь env-переменную `OPENAI_API_KEY` (нужна для семантического поиска в рантайме).
3. Привяжи домен: Project → Settings → Domains → добавь домен и пропиши у регистратора DNS-записи, которые покажет Vercel.
